# Лабораторна робота: Вбудовані колекції Python, їх семантика та алгоритмічна складність 
 
В лабораторнії роботі було досліджено вбудовані типи та структури даних Python — списки, кортежі, словники та множини: створення, індексація, зрізи, модифікація, comprehension-вирази.

# Структура проєкту 

* task 1: списки — індексація, зрізи, мутації 
* task 2: кортежі, розпакування
* task 3: словники та облік частот 
* task 4: множини, перетин/об’єднання/симетрична різниця
* task 5: алгоритмічна складність і обґрунтування вибору структури

# Інструкція з запуску

Для запуску необхіден Python 3.8 або новішої версії.
